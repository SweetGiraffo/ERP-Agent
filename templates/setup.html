How to get credentials.json:

  1. Go to Google Cloud Console.
  2. Create a new project or select an existing one.
  3. Enable the Gmail API for your project.
  4. Create credentials (OAuth client ID) for a Desktop application.
  5. Download the JSON file and rename it to credentials.json.
  6. Place it in the same folder as this app (or the path you set above).
  7. The first time the agent runs, it will open a browser for OAuth consent and generate token.json automatically.
